This is a tabletop simulator for the TTRPG game Pathfinder 2E.

Clone the repository from Github

Install Node.js

Install server dependencies "npm install" in the server folder

Start the backend server "npm run dev" in the server folder

Install client dependencies "npm install" in the client folder

Start the frontend "npm run dev" in the client folder

Open your browser and access the web page http://localhost:5173
